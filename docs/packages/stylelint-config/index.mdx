## Installation

```bash
pnpm add -D @lobehub/stylelint-config stylelint
```

## Usage

Create `stylelint.config.mjs`:

```js
export { default } from '@lobehub/stylelint-config';
```

## What's Included

- Extends `stylelint-config-standard`, `stylelint-config-recommended` and `stylelint-config-clean-order`
- `.css` and `.less` files use `postcss-less` with `stylelint-less`
- JS and TS files are not linted: CSS-in-JS support (`postcss-styled-syntax`) was dropped because it installs TypeScript. Lint StyleX styles with the `stylex` option of the [ESLint](/packages/eslint-config) or [Oxlint](/packages/oxlint-config) config
- `stylelint-use-logical-spec` enforces logical properties, except `float` and width/height; property names inside `transition`, `transition-property` and `will-change` values are left alone (the animated property must match what changes at runtime)

See every rule with its level and options on the [Rules](/rules/stylelint) page.

## Extending

```js
import config from '@lobehub/stylelint-config';

export default {
  ...config,
  rules: {
    ...config.rules,
    'color-hex-length': 'long',
  },
};
```

## Requirements

- Node.js 18+
- Stylelint 16+
