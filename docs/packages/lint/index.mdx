## Installation

```bash
pnpm add -D @lobehub/lint
```

Then install the tools you use:

```bash
pnpm add -D eslint prettier stylelint @commitlint/cli remark-cli semantic-release typescript
```

## Usage

```js
// eslint.config.mjs
import { defineConfig } from '@lobehub/lint';

export default defineConfig({ react: true });
```

```js
// prettier.config.mjs
import { prettier } from '@lobehub/lint';

export default prettier;
```

The other tools follow the same pattern with the exports below.

### Changelog options

The release notes are rendered by conventional-changelog-gitmoji-config, which reads `.changelogrc*` with cosmiconfig 7: CommonJS only, `.changelogrc.mjs` is never read. Use the CommonJS-safe subpath:

```js
// .changelogrc.cjs
module.exports = require('@lobehub/lint/changelog');
```

`require('@lobehub/lint')` does not work (the ESLint plugins are ESM-only); `@lobehub/lint/changelog` only loads the options object.

semantic-release 21 / 22 with cosmiconfig 8.0 / 8.1 (as locked by pnpm in some repos) does not read `.releaserc.mjs` either. Use `.releaserc.cjs`, or semantic-release 23+:

```js
// .releaserc.cjs
module.exports = require('@lobehub/lint/release'); // or '@lobehub/lint/release-monorepo'
```

## Exports

| Export                                           | Description                              |
| ------------------------------------------------ | ---------------------------------------- |
| `defineConfig` / `defineEslintConfig` / `eslint` | ESLint config factory                    |
| `EslintOptions`                                  | Type of the ESLint options               |
| `prettier`                                       | Prettier config                          |
| `stylelint`                                      | Stylelint config                         |
| `commitlint`                                     | Commitlint config                        |
| `remarklint`                                     | Remarklint config                        |
| `semanticRelease`                                | Semantic Release config                  |
| `semanticReleaseOptions`                         | Options used to build the release config |
| `semanticReleaseMonoRepo`                        | Monorepo Semantic Release config         |
| `changelog`                                      | Changelog formatting options             |

`@lobehub/lint/changelog`, `@lobehub/lint/release` and `@lobehub/lint/release-monorepo` default-export `changelog`, `semanticRelease` and `semanticReleaseMonoRepo` in CommonJS and ESM, for `.changelogrc.cjs` and `.releaserc.cjs`.
