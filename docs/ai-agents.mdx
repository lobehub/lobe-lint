## Prompt

Copy this prompt into your coding agent:

```text
Read https://lint.lobehub.com/skills.md, then set up LobeHub lint in this project: run `npx create-lobe-lint --preset -y`, run ESLint and Prettier on the codebase and fix the reported problems until both pass.
```

To upgrade a repo from v1 instead, start with `npx skills add lobehub/lobe-lint` and ask the agent to follow the `lobe-lint-v2-migration` skill. See [Migrating to v2](/migration-v2).

## Working on Lobe Lint

Agents that change this repository should read [AGENTS.md](https://github.com/lobehub/lobe-lint/blob/master/AGENTS.md): commands, architecture, and how to add a config package or rule.
